# ADR-0008: v0.1.0 Release Packaging (DMG, ad-hoc signed)

> Status: **accepted**
> Date: 2026-08-05
> Supersedes: ADR-0005 packaging detail ("`.app` zip" download artifact)

## Context

The v0.1.0 milestone (pointer + keyboard + system-shortcut suppression + Korean
2-set, on-device verified) is complete and needs a distributable artifact.
ADR-0005 chose "ad-hoc signed `.app` zip" for GitHub Releases because there is no
Apple Developer account; that path still stands, but v0.1.0 should ship an
improved artifact: a DMG.

DMG advantages over a raw `.app` zip:

1. **First-run experience**: dragging `Ampersand.app` to `/Applications` inside a
   Finder window is the canonical macOS install gesture, more trustworthy to
   users than unzipping a bundle.
2. **Single artifact**: one `~/.ammperand.dmg` file to download, verify shadow,
   and mount — no nested zip.
3. **Surface for user guidance**: the DMG can visually show the target folder
   (open readme/install link), which is where the "right-click → Open once"
   step belongs anyway.

## Decision

1. **v0.1.0 ships as `Ampersand-0.1.0.dmg` on GitHub Releases**, containing
   `Ampersand.app` (ad-hoc signed, `codesign -s -`, arm64).
2. Artifact naming: `Ampersand-<version>.dmg` (versions from
   `CFBundleShortVersionString`; the script reads it from `Info.plist`, no
   manual sync).
3. The user still must do right-click → Open once on first launch
   (Gatekeeper; no Developer ID), and the mac app might need a second
   right-click → Open for the helper's adb if it is shipped separately —
   documented in the README.
4. No Developer ID / notarization in v0.1.0 (no account). Re-evaluation
   remains per ADR-0005 decision 3.
5. Packaging stays reproducible: `scripts/package-macos.sh release` builds the
   `.app`, and `scripts/package-macos.sh dmg` (new) wraps it with `hdiutil
   create`. No new toolchain dependency (hdiutil ships with macOS).

## Alternatives

- **Raw `.app` zip** (ADR-0005, original): simplest but weaker install UX and
  imports the "unzip then move" heuristic.
- **Homebrew cask** for v0.1.0: frictionless but requires a tap repository +
  version choreography now; postponed (ADR-0005).
- **Notarized Developer ID DMG**: only with a $99 account — out of scope for
  v0.1.0 (no account).

## Consequences

- Positive: canonical install UX without an account; single artifact; guidance
  surface.
- Positive: packaging script remains local/dev reproducible; no external
  signing service.
- Negative: first launch still blocked by Gatekeeper once (right-click → Open);
  not as smooth as notarized apps.
- Negative: a stale `.app` in `/Applications` won't update automatically; DMG
  re-download is the update path for v0.1.0.

## Validation

- (this ADR) `scripts/package-macos.sh dmg` produces a mountable DMG;
  `hdiutil attach/verify` succeeds; `codesign --verify Ampersand.app` passes
  (ad-hoc).
- (this ADR) Drag to `/Applications` and right-click → Open launches the app
  on macOS 14+ (arm64) — verified on the build machine.
- Revisit when a Developer ID account is obtained (gate: adoption demand).
